CFR Dashboard — Support

CFR Dashboard for Jira (Atlassian Marketplace, Jira Cloud)

Contact

E-mail: support@cfrdashboard.app

Support is provided on a best-effort basis, without a formal service level agreement (see section 2.6 of the End User Terms). We read every message and reply as soon as we can, typically within a few business days.

Before you write

Many questions are answered in the documentation: connecting a repository, the access token permissions, how reverts are detected, CSV export and BigQuery / Amazon S3 sync.

A frequent cause of an empty or failed dashboard is an expired or under-privileged Git token. The error message on the dashboard names the provider and the HTTP status (for example 401 Bad credentials); replacing the token under Project settings → Apps → CFR Dashboard usually solves it.

What to include in a bug report

  • Your Jira Cloud site URL and the project key.
  • The Git provider (GitHub, GitLab, Bitbucket Cloud or Azure Repos) and the repository name.
  • The exact error message shown in the app, and what you expected to see.
  • Steps to reproduce, and a screenshot if helpful.

Please never send access tokens, passwords or other credentials by e-mail. We will never ask for them.
