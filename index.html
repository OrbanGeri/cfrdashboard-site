CFR Dashboard for Jira

An Atlassian Forge app by Gergely Orbán

CFR Dashboard calculates the DORA Change Failure Rate and Mean Time to Restore for a Jira project by detecting revert commits in the connected Git repository (GitHub, Bitbucket Cloud, GitLab.com or Azure Repos). It can also export deploy and revert events as CSV, or to your own BigQuery table or Amazon S3 bucket.
